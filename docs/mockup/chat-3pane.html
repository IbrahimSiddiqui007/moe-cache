How does moe-cache decide which experts stay in RAM? Keep it short.
Thought for 2.1 sThe user wants a short answer about the cache policy...

It counts how often each expert is used and keeps the most used ones in RAM:

  • Pinned set. At start it loads the experts that were used most in earlier runs (the learned profile), up to the RAM budget.
  • Misses. An expert that is not in RAM is read from the SSD for that token, then may replace a colder one.
  • Exact mode never skips an expert, so the answer is the same as stock llama-server; Fast may skip a rare one that is not in RAM.
