Other benchmarks (model quality)

MMLU-Pro, GPQA, GSM8K, HumanEval and the other capability benchmarks measure the model, not moe-cache; the scores must match stock. Run them with lm-evaluation-harness against a running server:

pip install lm-eval
lm_eval --model local-completions --model_args base_url=http://localhost:8080/v1/completions,model=any,num_concurrent=1 --tasks gsm8k,hellaswag --limit 200

Start the server with moe-cache-server MODEL.gguf --ram 24 (moe-cache) or plain llama-server -m MODEL.gguf (stock). Full list: docs/BENCHMARKS.md.
