2. What to measure

presets:
Identity (same tokens for stock and moe-cache) is checked automatically when both are selected. Deep metrics (SSD reads per token, page faults, cache hit rate, evictions, memory) are recorded for every request.
Settings: memory limits, GPU placement, extra arguments
Your own prompts
Quality: perplexity and KL divergence (advanced, slow)

Needs llama-perplexity next to llama-server and a plain text file (llama.cpp uses the Wikitext-2 test set). Stock records reference logits; moe-cache is compared against them (KL divergence 0 means identical).
